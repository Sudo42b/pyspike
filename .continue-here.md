<decisions_made>

- **credit_ld_chk/credit_st_chk are functional-model NOPs**. Functional model
  serializes S-loop and T-loop, so spin-lock semantics naturally satisfy.
  Visibility is owned by `end_p` (when not `wsplit_seen`) and `__join`
  (`wjoin_with_exit`). Matches C++ Spike comment verbatim.
- **memory.py aliasing**: byte view (`self.l[012]`) and FP16 view
  (`.view(torch.float16)`) must share storage. `torch.stack(...)` copies and
  `.to(torch.float16)` casts (creates new tensor) — both break aliasing.
  Verified empirically: `.view` returns same `data_ptr`, `.to` returns
  different `data_ptr`.
- **dispatch.py / dispatch_state.py circular import**: pyspike's
  `gtx/__init__.py:54-67` wraps `from . import npu` in
