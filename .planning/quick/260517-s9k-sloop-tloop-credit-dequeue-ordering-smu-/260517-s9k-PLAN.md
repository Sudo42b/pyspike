<objective>
Add a per-unit S-loop instruction buffer (`_sloop_buf`) symmetric to the existing
T-loop buffer (`_tloop_buf`), and wire **credit-gated dequeue semantics** on
`credit_ld_chk` (TMU side) and `credit_st_chk` (SMU side) so the producer-consumer
SMU/TMU pair drains in a deterministic, deferred-flush-safe order:

```
P-loop (start_p..end_p) — per-NEST broadcast
   ├── SMU (start_s..end_s) — DMA only (DDR<->L2)  -> opens _sloop_buf
   └── TMU (start_t..end_t) — Compute (L2/L1)      -> opens _tloop_buf
```

The existing `_credit_ld` / `_credit_st` handlers (already populating
`npu._credit_ld[nest, spu]` / `npu._credit_st[nest, spu]` tensors at
`unit/context/dma.py:314-353`) already encode the producer side. This plan
adds the **consumer-side dequeue** at the two `chk` handlers, plus the
S-loop buffer/drain scaffolding that mirrors `tloop_buffer.py`.

Purpose:
  - Make the SMU/TMU producer-consumer relationship explicit in the FSM,
    eliminating ordering races even though the functional model executes
    sequentially. This is parity scaffolding for the vendor SystemC
    cycle-accurate path (`vendor/gtx_cpp_reference/gtx/gtx_npu_dispatch.cc:41-61`),
    where `use_spu_queue` / `use_tmu_queue` push opcodes on credit stall.
  - **CRITICAL non-regression**: the existing `_credit_ld_chk` is a
    documented NOP (see `unit/context/dma.py:358-376`) because the prior
    Plan 04 attempt to call `flush_deferred_ddr_stores()` from it broke
    ADD-style firmware whose shared block sandwiches `__credit_chk` BETWEEN
    successive `__store` calls. The new dequeue mechanism MUST NOT
    re-introduce that broken behavior — deferred-store visibility stays
    owned exclusively by `end_p` (when `!wsplit_seen`) and `wjoin`.

Output:
  - `src/main/python/riscv/gtx/sloop_buffer.py` (new): SLoopEntry namedtuple,
    `try_buffer`, `flush`, mnemonic sets — minimal scaffold (NO fusion;
    sequential replay only, since SMU ops are DMA + control, not the
    1.18M-entry vec hot loop tloop_buffer is optimized for).
  - `npu.py`: `_sloop_buf` slot, reset() wiring, custom0 dispatch branch
    for S-loop snapshot.
  - `unit/context/control.py`: `_do_starts` opens buffer, `_do_ends` drains.
  - `unit/context/dma.py`: `_credit_ld_chk` / `_credit_st_chk` upgraded
    from documented NOP -> per-batch dequeue (S-loop first when both
    buffers non-empty), preserving the existing `deferred_ddr_stores`
    flush boundaries (end_p / wjoin) untouched.
  - `tloop_buffer.py`: `TRANSPARENT_MNEMONICS` comment updated to reflect
    that `credit_*_chk` is no longer fully transparent — it drains the
    T-loop buffer at the chk boundary (TMU side).
</objective>
