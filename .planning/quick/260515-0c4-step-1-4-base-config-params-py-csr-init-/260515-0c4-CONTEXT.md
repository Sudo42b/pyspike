## Implementation Decisions

### A — base 재정의 제거 방향

**Source of truth: `csr/__init__.py`** (csr 모듈 docstring 이 scope-encoding
을 명시; address space 정의가 csr 책임).

변경:

1. `src/main/python/riscv/gtx/config_params.py:41-51` (block "SPR address
   ranges ..." docstring + 6 상수) 전부 삭제. 단 docstring 줄 (line 41-45)
   은 메모리 토폴로지 정보로 가치 있으니 짧게 1-2 줄 주석으로 보존하거나
   완전히 csr 로 이전. **간결성 우선 → 6 상수 + docstring block 모두 삭제**.

2. `src/main/python/riscv/gtx/unit/context/spr_router.py:27-28` 의 import:

   ```python
   from ...config_params import (GSPR_BASE, GSPR_END, NSPR_BASE, NSPR_END,
                                 LSPR_BASE, LSPR_END, GTX_NEST_NUM, GTX_SPU_NUM)
   ```

   → 두 import 로 분리:

   ```python
   from ...config_params import GTX_NEST_NUM, GTX_SPU_NUM
   from ...unit.csr import (GSPR_BASE, GSPR_END, NSPR_BASE, NSPR_END,
                            LSPR_BASE, LSPR_END)
   ```

   (`spr_router.py` 는 `unit/context/` 안에 있으므로 sibling package `..csr`.
   현재 `...config_params` 와 일관: 셋째 `...` 이 `gtx/` 패키지 루트.)

### B — dma.py NameError fix

`src/main/python/riscv/gtx/unit/context/dma.py:18-27` import block:

```python
from ..ins.encoding import (
    # GSPR_GTX_OPERAND3,                      # 0x003 -- gtx_params.h:40
    # LSPR_SPM_ADDRA, LSPR_SPM_ADDRR,         # 0x900 / 0x903 -- gtx_params.h:64,67
    # GTX_ISS_F7_DMA_TPOSE, GTX_ISS_F7_DMA_FILL,
    GTX_ISS_F7_DMA_LD_ST, GTX_ISS_F7_DMA_3D,
    GTX_ISS_F7_DMA_MCAST_S2L, GTX_ISS_F7_DMA_LD_SVR_L1,
    GTX_ISS_F7_DMA_MCAST_GS, GTX_ISS_F7_DMA_ST_SVR_L1,
    GTX_ISS_F7_CREDIT_LD, GTX_ISS_F7_CREDIT_ST,
    GTX_ISS_F7_CREDIT_LD_CHK, GTX_ISS_F7_CREDIT_ST_CHK,
)
```

수정:

- **`GSPR_GTX_OPERAND3` 주석 해제** — 이 task 의 핵심. dma.py:70/101/132
  가 사용 중.
- **`LSPR_SPM_ADDRA, LSPR_SPM_ADDRR` 주석 처리 유지** — encoding.py 에 정의
  없음 (vjk 가 OPERAND0..5 만 추가; SPM_ADDR 은 csr/lspr.py 에 `SPM_ADDRA`
  등 짧은 이름으로만 등록). dma.py:195-215 에서 사용 중이라 NameError
  잠재이지만 이건 **Step 2/3 (패턴 통일 + 누락 register 정리)** 의 범위.
- **`GTX_ISS_F7_DMA_TPOSE, GTX_ISS_F7_DMA_FILL` 주석 처리 유지** — dma.py
  본문에서 사용 안 함 (다른 모듈에서 처리). 검색해서 dma.py 안 사용 site
  없음을 확인 후 그대로 둠.

검증: `grep -n "GTX_ISS_F7_DMA_TPOSE\|GTX_ISS_F7_DMA_FILL" src/main/python/riscv/gtx/unit/context/dma.py`
가 0 matches 이면 OK.
